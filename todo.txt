I have LMS-1 (Moodle 4.3) with a course C-1 that I want to share with another LMS-2 (Moodle 4.3).
The goal is to export C-1 as an AICC package, which may include PDFs, audio, video, or SCORM activities.
LMS-2 will import this AICC package as a SCORM activity within a course (e.g., C-2) and access content via HACP.

Main Challenge

We need tracking and progress synchronization between both LMSs.
Example:

A teacher on LMS-2 creates course C-2, adds the AICC-based SCORM activity.

Students (S1, S2, S3, etc.) self-enroll and access C-1 through that activity.

LMS-1 should display which external users (from LMS-2) are accessing C-1 and their progress (slides viewed, quizzes passed, etc.).

When students return, their progress should resume, not reset.

Tracking data should be available on both LMSs.

Proposed Solution

Plugin 1 (LMS-1):
Exports a course as an AICC package, embedding links to LMS-1 plus authentication tokens/keys.

Plugin 2 (LMS-1):
Handles tracking, authentication, and communication via HACP (e.g., student identity, progress, completion data).

Optional Plugin 3 (LMS-2):
Only if necessary—facilitates viewing the shared course and sending user/progress data back to LMS-1.

ToDo:

Plugin B (LMS-1 – HACP handler): Moodle doesn’t natively act as an AICC host. we need a custom endpoint to receive and log HACP messages (e.g., GetParam, PutParam, ExitAU).

Handles requests from LMS-2 (student launch, progress, completion).

(Optional) Plugin C (LMS-2 – enhancer):

If HACP posts aren’t reaching LMS-1 correctly (due to JS sandboxing, CSP, or missing params), you’ll need Plugin 3 on LMS-2 to handle the communication cleanly.
