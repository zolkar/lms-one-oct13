# AICC HACP Handler Plugin

This plugin provides an AICC HACP (HTTP AICC CMI Protocol) endpoint for Moodle. It allows Moodle to act as a content provider for other Learning Management Systems (LMS) that support the AICC standard.

## Installation

1.  Copy the `aicc_hacp` directory to the `local` directory of your Moodle installation.
2.  Log in to your Moodle site as an administrator and go to "Site administration" -> "Notifications".
3.  Moodle will automatically detect the new plugin and prompt you to install it. Follow the on-screen instructions to complete the installation.

## Configuration

1.  Go to "Site administration" -> "Plugins" -> "Local plugins" -> "AICC HACP Handler".
2.  This page will display a table of user mappings and their corresponding tracking data. This is useful for debugging and monitoring the system.

## Usage

This plugin works in conjunction with the AICC Export plugin. When a user from a remote LMS launches a course that was exported from this Moodle instance, this plugin will handle the HACP communication, user mapping, and progress tracking.

## Security

This plugin implements several security features to protect your Moodle instance from unauthorized access and abuse.

### Token Expiration

The launch URL generated by the AICC Export plugin includes a security token that is valid for a limited time. The duration of this token can be configured in the AICC Export plugin settings.

### Allowed Origins

You can configure a whitelist of allowed domains that can access the HACP endpoint. This is a crucial security feature that prevents other domains from sending requests to your HACP endpoint. You can configure the allowed origins in the AICC HACP Handler plugin settings.

### Rate Limiting

The HACP endpoint implements IP-based rate limiting to prevent abuse. You can configure the maximum number of requests allowed per minute per IP address in the AICC HACP Handler plugin settings.

### Limitations of HACP

The AICC HACP standard is an old standard and has some inherent security limitations. The communication between the remote LMS and your Moodle instance is not encrypted and is vulnerable to man-in-the-middle attacks. For this reason, we strongly recommend that you only use this plugin in a trusted environment.

For a more secure solution, you can develop a custom plugin for the remote LMS that implements a more robust security model, such as HMAC signatures.
